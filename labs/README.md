# الطلاقة في البيانات والذكاء الاصطناعي لطلبة الجامعات: المختبرات

عشرة مختبرات لمقرر أكاديمية سدايا **USE-EDU-101**، مختبر في كل أسبوع مدته 60 دقيقة. المختبرات صفحات إرشادية بالعربية:
الهدف، والملفات، وخمس خطوات بدقائقها، وأسئلة تحقق، وتمرين إضافي ✱، وملاحظات للمدرّب. لا كود يكتبه الطالب.

كل المختبرات في جهة واحدة: **جامعة السنديان**، جامعة حكومية افتراضية، ولجنة البيانات والذكاء الاصطناعي في مجلس طلبتها.
كل الأسماء والأرقام والوثائق اصطناعية ومولّدة ببذرة ثابتة، عدا جدول المختبر 3.1 المأخوذ من البيانات المفتوحة للبنك
الدولي (سنة 2022، ثلاثون دولة، رخصة CC BY 4.0).

## ما يحتاجه الطالب

- متصفح، والمساعد الذي تعتمده الجامعة، أو خطة مجانية لمساعد مستضاف. لا يُنزَّل أي نموذج على الجهاز.
- جدول بيانات: LibreOffice Calc أو Microsoft Excel.
- للمختبر 4.1: Orange Data Mining، أو أداة بناء نماذج دون برمجة تعمل في المتصفح. لمن لا تتاح له الأداة ملف بديل
  جاهز (`files/week4/classifier_fallback.xlsx`) يؤدي المختبر كله في جدول بيانات.
- ملف الأعمال: `files/portfolio_tracker.xlsx`، وفيه سطر لمخرج كل أسبوع.

حاسوب محمول عادي يكفي. لا يحتاج أي مختبر بطاقة رسوميات ولا حسابًا مدفوعًا.

## تشغيل الحلول

```bash
uv run labs/solutions/check.py            # كل المختبرات
uv run labs/solutions/check.py 5.1 9.1    # بعضها
```

ملف واحد يعلن اعتمادياته، ويحتاج [uv](https://docs.astral.sh/uv/). يطبع لكل مختبر ما أعاد حسابه ثم `PASS`، ولا يكتب
شيئًا على القرص ولا يتصل بأي نموذج.

**ما يُشغَّل فعلًا دون نموذج:**

- 2.1: مفتاح السيناريوهات العشرة ومواضعها.
- 3.1 (الخطوات 1 إلى 4): كل رقم يُعاد حسابه من جدول البنك الدولي: الفروق، ومعاملات الارتباط، ونسبة الارتفاعين في الرسم المقطوع.
- 4.1: تدريب مصنِّف واختباره على البيانات الأصلية والمتغيرة. المرجع يستخدم شجرة قرار من scikit-learn بديلًا من الأداة التي يستخدمها الطالب.
- 5.1: جدول الأخطاء، والحساب بالأعداد عند ثلاثة معدلات أساسية، والفرق بين الفئتين.
- 9.1: عدّ المعرّفات، وفحص الأمر المنقّح، وتجربة خطة من سبعة أفعال على سياسة البوابة.
- 10.1: أرقام ورقة التكلفة، وأقسام النموذج، والمشكلات المزروعة في المسودة الضعيفة.

**ما يُشغَّل بنموذج بديل:** كل خطوة يؤديها الطالب في مساعد محادثة: 1.1، والخطوة 5 من 3.1، و6.1، و7.1، و8.1، ورد
المساعد على الأمر المنقّح في 9.1. النموذج البديل (`solutions/standin.json`) ردود مكتوبة فيها الأخطاء التي يقع فيها
مساعد حقيقي، ليُظهر كل فحص أن خطوة التحقق في المختبر تلتقطها. **لم يُشغَّل أي مختبر على نموذج حقيقي**، ولم تُجرَّب
صفحة المختبر 4.1 في Orange ولا في أداة المتصفح. يجرّب المدرّب هذه المختبرات بمساعد الجامعة قبل كل دفعة، ويتوقع أن
تختلف الأرقام في شرائح «في التشغيل المرجعي» عمّا يراه الطلبة.

## إعادة توليد الملفات

ملفات `files/` مولّدة ببذرة ثابتة. النصوص في `_tools/texts.py`، وجدول البنك الدولي المحفوظ في `_tools/public/`، والمولّد:

```bash
uv run labs/_tools/prepare_files.py
```

يعيد كتابة `files/` و`solutions/reference/`. بعد أي تعديل شغّل `uv run labs/solutions/check.py`.
